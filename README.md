# 💕 6 Years of Us

A playful anniversary website made with plain HTML, CSS and JavaScript.

## Folder structure

anniversary_website/
├── index.html
├── style.css
├── script.js
└── images/
    ├── photo1.jpg
    ├── photo2.jpg
    ├── photo3.jpg
    └── photo4.jpg

## Add your photos

Put your own photos inside the `images` folder and name them:

- photo1.jpg
- photo2.jpg
- photo3.jpg
- photo4.jpg

Or edit the image names in `index.html`.

## Run locally

Double-click `index.html` or open it with a browser.

## GitHub Pages

1. Create a GitHub repository.
2. Upload all files and the `images` folder.
3. Go to Settings → Pages.
4. Select Deploy from branch.
5. Select the `main` branch and `/ (root)`.
6. Save.
7. GitHub will give you your website URL.

## Customize

Edit the text in `index.html` and `script.js` to add your own:
- Names
- Nicknames
- Memories
- Inside jokes
- Anniversary message
- Photos
